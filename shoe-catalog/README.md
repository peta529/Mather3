# Каталог взуття — інструкція із запуску на Vercel

Сайт складається з двох частин:
- **`/`** — публічний каталог. Його бачать усі, кому дасте посилання: тільки фото та інформація про товар, без жодних кнопок керування.
- **`/admin`** — захищена паролем сторінка для вас і мами: тут можна додавати, редагувати й видаляти товари.

Дані (назва каталогу, товари) і фото зберігаються на самому сайті, у вбудованому файловому сховищі Vercel (Vercel Blob) — воно безкоштовне для такого невеликого каталогу.

## Крок 1. Встановіть інструменти (один раз)

1. Встановіть Node.js, якщо його ще немає: https://nodejs.org (версія LTS).
2. Встановіть Vercel CLI — відкрийте термінал і виконайте:
   ```
   npm install -g vercel
   ```

## Крок 2. Завантажте сайт на Vercel

1. Розпакуйте цей проєкт у папку на комп'ютері.
2. У терміналі перейдіть у цю папку (`cd шлях/до/папки`).
3. Виконайте:
   ```
   vercel
   ```
   Увійдіть у свій акаунт Vercel (якщо його немає — реєстрація безкоштовна), і відповідайте на питання за замовчуванням (Enter на кожне).
4. Дочекайтесь, поки з'явиться посилання на сайт — поки що він ще не буде працювати повністю, бо не вистачає двох налаштувань нижче.

## Крок 3. Підключіть сховище файлів (Vercel Blob)

1. Зайдіть у панель керування на vercel.com → відкрийте свій проєкт.
2. Перейдіть у вкладку **Storage** → **Create Database** → виберіть **Blob**.
3. Access mode виберіть **Public**, натисніть створити й підключити до проєкту (Connect to Project) — Vercel сам додасть потрібну змінну середовища.

## Крок 4. Задайте пароль для адмінки

1. У проєкті перейдіть у **Settings** → **Environment Variables**.
2. Додайте змінну:
   - Name: `ADMIN_PASSWORD`
   - Value: ваш спільний пароль (для вас і мами)
3. Збережіть.

## Крок 5. Перезапустіть сайт, щоб налаштування підʼїхали

У терміналі, в тій самій папці, виконайте:
```
vercel --prod
```

## Готово 🎉

- **Публічний каталог для клієнтів:** `https://ваш-проєкт.vercel.app`
- **Адмінка для вас і мами:** `https://ваш-проєкт.vercel.app/admin` — вхід за паролем із кроку 4.

При першому вході в адмінку попросить заповнити назву каталогу, короткий опис і, за бажанням, посилання для звʼязку (WhatsApp/Telegram). Далі просто тиснете «+ Додати товар» і завантажуєте фото, ціну, розмір і опис.

## Якщо потрібно щось змінити пізніше

- Змінити пароль адмінки — оновіть значення `ADMIN_PASSWORD` у Environment Variables і зробіть `vercel --prod` ще раз.
- Змінити назву каталогу, опис чи контакт — кнопка «Налаштування» в адмінці.
- Дизайн, кольори, тексти — попросіть Клода змінити код і надішліть оновлені файли.
